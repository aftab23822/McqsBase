## How to revise this ISSB Verbal Reasoning Practice set

1. For an analogy, state the relationship in a short phrase before looking at the options; this helps avoid choosing a pair that is related in a different way.
2. For a sequence, write the differences between terms first. If those do not explain it, test ratios or alternating patterns rather than guessing.
3. When solving letter codes, convert letters to alphabet positions only if the rule calls for it, and apply the same rule to every letter.
4. Draw a quick arrow or family tree for direction and relationship questions. Keep the starting direction fixed while applying turns in order.
5. In logic questions, accept only conclusions guaranteed by the statements. In particular, if A implies B, B alone does not prove A.
6. For percentages, ratios and rates, write the base quantity and units. Recheck whether a question asks for a part, a total, a distance or a rate.

### What should I do if a question feels unfamiliar?

Translate the wording into a small representation, such as a sequence of differences, an arrow for a turn, or a short list of premises. If more than one interpretation still seems possible, focus on the stated assumptions rather than inventing extra conditions.
