## How to revise this Computer Literacy for Clerical Recruitment Tests set

1. For device questions, classify each item by its main role: input, output, processing, memory or storage. Some devices perform more than one role, so use the role specified in the question.
2. Practise file extensions and confirm the application or file type they commonly indicate; an extension identifies a format but does not guarantee that a file is safe.
3. Before selecting a word-processing command, identify whether the task concerns character formatting, paragraph layout, page layout or document review.
4. For spreadsheet questions, write out the formula and substitute the referenced values. Check whether a reference is relative or absolute before copying a formula.
5. When a question involves email or a link, consider the recipient, privacy and sender authenticity before deciding what action is safe.
6. For troubleshooting questions, start with the simplest relevant check, such as power, connection, selected device or application settings, rather than immediately deleting data or changing system settings.
